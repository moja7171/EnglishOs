# راه‌اندازی رله‌ی AI برای English OS روی VPS

سلام! ممنون که کمک می‌کنی. این یه سرویس خیلی کوچیکه که باید روی VPS تو اجرا بشه. خلاصه‌ش:

**چیه؟** سایت English OS روی یه هاست ایرانیه و از اونجا نمی‌شه به API گوگل (Gemini) و Groq وصل شد. این سرویس یه «پل» کوچیکه: سایت درخواستش رو به VPS تو می‌فرسته، VPS همون درخواست رو عیناً به گوگل/Groq می‌رسونه و جواب رو برمی‌گردونه. همین.

**چقدر سنگینه؟** تقریباً هیچی — یه اسکریپت پایتون ۱۲۰ خطی + Caddy برای HTTPS. کمتر از ۵۰ مگابایت رم، ترافیک خیلی کم (فقط متن). روی کوچک‌ترین VPS هم راحت کنار سرویس‌های دیگه کار می‌کنه.

**امنیتش؟**
- فقط به ۳ مقصد مشخص اجازه‌ی ارسال داره (googleapis، groq، pexels) — به هیچ جای دیگه‌ای وصل نمی‌شه، پس نمی‌شه ازش به‌عنوان پروکسی عمومی سوءاستفاده کرد.
- هر درخواست باید یه رمز مخفی داشته باشه، وگرنه رد می‌شه (کد ۴۰۱).
- با یوزر جداگانه‌ی بدون دسترسی اجرا می‌شه، فقط روی `127.0.0.1` گوش می‌ده و Caddy جلوشه.
- کلیدهای API خودِ ما داخل درخواست‌ها رد می‌شن؛ سرویس اون‌ها رو ذخیره نمی‌کنه.

## چی لازمه

- VPS با Ubuntu 22/24 یا Debian 12، **خارج از ایران** (Gemini از ایران/روسیه در دسترس نیست)
- دسترسی root (یا sudo)
- پورت‌های 80 و 443 باز باشن (برای گواهی HTTPS خودکار) — اگه Caddy یا nginx از قبل روی 80/443 داری، پایین رو ببین
- دو فایلی که همراه این متنه: `vps-relay-setup.sh` و `ai-relay.py`

## مراحل (۳ دقیقه)

۱. دو فایل رو بذار توی `/root/` روی VPS (مثلاً با scp).

۲. این رو به‌عنوان root اجرا کن (رمز داخل دستور هست — همین رو عیناً کپی کن):
```bash
RELAY_SECRET='fzw8cdT0zeKShb_nVEp_mSppOOlAFYud' RELAY_SOURCE=/root/ai-relay.py bash /root/vps-relay-setup.sh
```
اسکریپت خودش پکیج‌ها رو نصب می‌کنه، سرویس systemd می‌سازه، Caddy رو با HTTPS بالا میاره (آدرس خودکار `<IP>.sslip.io`، بدون نیاز به DNS)، فایروال رو تنظیم می‌کنه (SSH/80/443 — پورت SSH رو خودش از تنظیمات می‌خونه که قفل نشی)، و آخرش تست می‌کنه.

۳. آخر اجرا باید این رو ببینی:
```
Relay is up: https://<IP>.sslip.io/  (401 = healthy ...)
```

۴. **فقط همین یه خط رو برام بفرست**: آدرس `https://...sslip.io` — بقیه‌ش با من.

## اگه از قبل Caddy/nginx داری

اسکریپت `/etc/caddy/Caddyfile` رو بازنویسی می‌کنه. اگه Caddy رو برای چیز دیگه‌ای استفاده می‌کنی، به‌جای اجرای کامل اسکریپت، فقط این بلاک رو به Caddyfile خودت اضافه کن (بعد از اینکه بخش «relay service» اسکریپت اجرا شده):
```
<IP>.sslip.io {
    reverse_proxy 127.0.0.1:8899
}
```
اگه nginx داری، یه server block با `proxy_pass http://127.0.0.1:8899;` و گواهی Let's Encrypt (certbot) برای همون hostname کافیه.

## نگهداری / حذف

```bash
systemctl status englishos-relay caddy     # وضعیت
journalctl -u englishos-relay -f           # لاگ زنده
```
حذف کامل:
```bash
systemctl disable --now englishos-relay; rm -rf /opt/englishos-relay /etc/englishos-relay.env /etc/systemd/system/englishos-relay.service; systemctl daemon-reload
```
